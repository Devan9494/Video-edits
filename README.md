# Video-edits

A lightweight web app concept for auto video editing with polished, fine-grained animations.

## Run locally

Open `/tmp/workspace/Devan9494/Video-edits/index.html` in a browser.

## Features

- Drag-and-drop video upload
- One-click auto edit simulation
- Animated timeline scrubber and preview pulse effects
- Preset-driven style selection for cinematic and social outputs
